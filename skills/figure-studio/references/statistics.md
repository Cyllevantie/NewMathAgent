# 图里的统计：先把“独立单位”说清楚

> 图可以简化，统计口径不能简化。没有真实区间就不画区间；没有真实检验就不写 p。
> 本文件是投稿统计规范的 figure-statistics 精简版，面向 CUMCM/数模论文。

## 1. 五个问题

画任何带不确定性/比较的图之前，先回答：

1. **独立单位是什么？** 一个时间点、一个对象、一个 seed、一次实验重复，还是一组汇总？
2. **n 是多少？** 每个组/面板的 n 是否写清？
3. **区间是什么？** SD、SE、95% CI、预测区间、情景区间，还是极差/IQR？
4. **有没有配对/重复测量？** 同一对象前后测、同一任务多方法，必须保留配对。
5. **有没有检验？** 如果有，什么检验、什么多重比较校正、p 值阈值？

答不出来，就不要画误差棒/CI/显著性星号。

## 2. 区间

| 名称 | 含义 | 什么时候用 | 常见错误 |
|---|---|---|---|
| SD | 个体间标准差 | 描述分布宽度 | 叫成 95% CI |
| SE | 均值标准误 | 均值的不确定性 | 当成个体分布 |
| 95% CI | 均值/参数的区间 | 有明确重采样/模型 | 用 SD 冒充 |
| 预测区间 | 单个新观测的区间 | 预测图 | 用 CI 冒充 |
| 情景区间 | 参数/口径范围 | 敏感性分析 | 叫成 CI |
| IQR / 极差 | 分布的中部/全距 | 箱线/描述 | 叫成 CI |

规则：

- 区间必须来自数据或明确的重采样（bootstrap/交叉验证/贝叶斯后验）；不能“均值 ± 某个数”凭空造。
- 图注写清区间类型、水平（95%）、重采样次数/单位。
- 同一张图多个面板的区间定义必须一致；不一致要分别标注。
- 只有汇总均值、没有个体观测时，不要画分布/箱线/云雨；画点区间或表。

## 3. 配对与重复

- 同一对象前后测：保留 subject ID，画配对线/配对差；不要拆成两组独立分布。
- 同一任务多方法：按任务配对；先算每个任务内的差，再看跨任务平均。
- 同一模型多 seed：seed 是重复单位；先在每个 seed 内聚合任务，再跨 seed 算均值/SD。
- 同一时间点多半径：半径不是独立重复；它是同一场内的空间点，不能当 n。
- 同一参数多口径：口径不是重复；它是敏感性情景，画点图/龙卷风，不画 CI。

## 4. p 值与多重比较

- 没有假设检验就不写 p；不要用 `*`/`**`/`***` 装饰。
- 有检验就写：检验名、双侧/单侧、配对/独立、多重比较校正（Bonferroni/Holm/BH）、显著性阈值。
- 多重比较未校正时，不要声称“显著”。
- p 值不表示效应大小；图里优先给效应量和区间，p 值放图注或正文。
- 不要因为 p>0.05 就说“没有差异”；区间宽可能只是样本小。

## 5. 模型比较

- 同一测试集/同一交叉验证折比较模型；不同数据划分不可直接比。
- 报告均值 + 波动（SD/SE/CI），并写清波动单位（seed/任务/折）。
- 不要只报最好 seed；不要只报测试集上的最优模型而不说选择过程。
- AUC≈1 时说明任务本身几乎完全可分，不代表模型强；改预测诊断/残差图。
- 分类指标要说明正类、阈值、类别平衡；不要只报 accuracy。

## 6. 拟合/预测

- 预测-观测图：画 1:1 线、RMSE、R²；大样本用 hexbin/密度，不抽稀。
- 残差图：残差 vs 预测/观测；分箱均值看条件偏差。
- 外推区要标出；不要把外推当内插。
- 平滑/拟合区间要说明方法（线性/多项式/样条/高斯过程）和置信水平。

## 7. 敏感性/收敛

- 敏感性：每个口径/参数是一个情景，不是重复；画点图/龙卷风/扫描线，不画 CI。
- 收敛：网格/步长/迭代是自变量；看是否进入平台；参考线写清基准。
- 不要用“最优口径”挑选结果；所有口径都展示，或说明排除规则。

## 8. CUMCM 特别提醒

- 正文页数有限：图注可以短，但 n/区间/排除规则不能省。
- 不要为了“看起来显著”加星号；评委更看重口径是否诚实。
- 不要写“由于 p<0.05，所以模型更好”；数模论文多数没有真实重复实验。
- 派生任务（分类、重建、代理模型）要明确写“派生”，不要冒充原模型结果。
- 试算/敏感性数据要标“同模型试算”，不要与提交版混用。

## 9. 图注模板

中文：

```text
图 X  <短标题>。
(a) <面板内容>；n = <n>，<独立单位>；(b) <区间类型>（<方法>，<水平>）。
数据为 <提交版/同模型试算/派生任务>；<排除规则>。无假设检验，未显示 p 值。
```

英文：

```text
Fig. X  <short title>.
(a) <panel content>; n = <n>, <independent unit>; (b) <interval type> (<method>, <level>).
Data are <submitted run / same-model trial / derived task>; <exclusion rule>. No hypothesis test; no p values are shown.
```
