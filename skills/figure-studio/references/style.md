# 统一画风：一套 tokens，四种来源共用

> **分类色/字体/字号/画布/3D 边线**的唯一来源是 `assets/style.tokens.json`；
> **连续量色阶**仍由 `config/visualization.json` 的 `quantity_cmap` 提供。本文件解释“为什么”，
> 不复制全部数值。任何脚本都不许另写一套 rcParams；要改画风，改 tokens 并在
> `studio.style(ctx)` 里生效；要改物理量色阶，改 `quantity_cmap`。

## 1. 配色：按角色，不按审美

### 分类序列（8 色）

```text
#1D4ED8 主蓝      #0F766E 蓝绿     #6D28D9 紫      #B45309 赭
#4D7C0F 橄榄      #475569 石板灰   #60A5FA 浅蓝    #BE123C 玫红
```

- 第 1 色是“本文方法/主结果”，第 2 色是“主要对照”，第 3 色是“正向/第二方法”，第 4 色是“基线/反差”，其余是更多方法与背景。
- 颜色不是唯一编码：≥5 条序列必须同时用线型 + 标记；灰度打印下相邻色可能合并。
- 相邻两档蓝不要用同线型；如果必须同线型，改用标记形状。

### 语义色

| 键 | 值 | 只用于 |
|---|---|---|
| `ink` | `#1F2937` | 主文字、数值标注 |
| `line` | `#475569` | 主结构线、轴线 |
| `grid` | `#E2E8F0` | 网格、背景级辅助 |
| `box` | `#CBD5E1` | 分组框、图例边 |
| `warn` | `#EF4444` | 阈值、异常、失败区域 |
| `positive` | `#15803D` | 增益、改进、通过 |
| `highlight` | `#D97706` | 每图一个 callout（如关键事件） |
| `muted` | `#94A3B8` | 背景对象、辅助线；不当文字色 |
| `paper` | `#FFFFFF` | 纸面/背景 |

`warn` 与 `positive` 不进入分类循环；`highlight` 每图最多一处；`muted` 不用来写正文。

### 连续量

| 量 | 色阶 | 方向 | gamma |
|---|---|---|---|
| temperature | inferno | 大=热=亮/橙黄 | 0.6 |
| moisture / concentration / diffusivity | viridis | 大=湿/浓/快=亮黄 | 0.5 / 0.5 / 0.45 |
| residual | Reds | 大=误差大=深红，0=近白（低端裁 0.35） | 1.0 |
| participation | Blues | 大=参与强=深蓝（低端裁 0.30） | 0.7 |
| axis_ratio | YlOrRd | 大=轴比大=深红（低端裁 0.30） | 0.6 |

- 同一量跨图同色；不同量不同色。
- 同图多栏共用 `vmin/vmax`；不要各栏按自身范围归一化。
- 低值区占一大片时先加 gamma；还平就改剖面/折线，不要只加一条判据线。
- 场图必须带色标，色标写清量与单位。

## 2. 字体与字号

### 中文（`zh` / `zh_half`）

| 项目 | 全宽 160 mm | 半栏 80 mm |
|---|---:|---:|
| 正文/轴标签 | 9 pt | 8 pt |
| 刻度 | 8 pt | 7 pt |
| 图例 | 8 pt | 7 pt |
| 面板字母 | 9.5 pt | 9 pt |
| 面板标题 | 9 pt | 8 pt |
| 注释 | 7.5 pt | 7 pt |
| 渲染下限 | 7.5 pt | 7 pt |

字体：Microsoft YaHei；fallback SimHei / Noto Sans CJK SC / DejaVu Sans。
中文图不要用 `$...$` 写单位/上下标；优先 Unicode；发现方框改 ASCII（`kg/kg`、`m2/s`）。

### 英文（`en` / `en_half`）

| 项目 | 全宽 183 mm | 半栏 88 mm |
|---|---:|---:|
| 正文/轴标签 | 7–8 pt | 7 pt |
| 刻度 | 6.5–7 pt | 6 pt |
| 图例 | 6.5–7 pt | 6 pt |
| 面板字母 | 8.5–9 pt | 8 pt |
| 面板标题 | 7.5–8 pt | 7 pt |
| 渲染下限 | 6 pt | 6 pt |

字体：Arial；fallback Helvetica / Liberation Sans / DejaVu Sans。
单位用 `°C`、`kg m⁻³`、`m s⁻¹`；中文用 `°C`、`kg/kg`、`m2/s`，不要混用中点与空格两种写法。

### 面板字母

- 小写粗体 a/b/c；放在 Axes 左上角外沿，物理偏移 5–7 mm，不用 axes 比例。
- 标题与字母间隔 3–4 mm；没有标题就只放字母。
- 不要用 20 pt 的巨型字母；不要放在图内压数据。

## 3. 轴线、网格、图例

- 只保留左/下 spine；颜色 `#475569`，全宽 0.8 pt / 半栏 0.7 pt。
- 网格只画 y 向（类别横条画 x 向），`#E2E8F0`，0.7 pt；`axes.axisbelow=True`；不要再叠 alpha。
- 刻度朝外，3 pt，标签 `#1F2937`。
- 图例：中文模板白底半透明（`framealpha=0.92`，边 `#CBD5E1`，0.6 pt）；英文模板只有在渲染检查无重叠时才可无框。图例不能压数据；压了改 loc/移出/直接标注。
- 多面板共享一个图例条；不要每个面板重复图例。

## 4. 线、标记、误差

- 线宽：全宽 1.2 pt，半栏 1.0 pt；坐标轴 0.8/0.7。
- 稀疏序列加标记（o s ^ D v P X *）；密集曲线不加逐点标记，用线型区分。
- 误差带 alpha 0.17；误差棒 capsize 3 pt，线宽 1 pt；误差棒定义（SD/SE/CI/预测区间）写在图注。
- 没有真实区间就不画误差棒；没有真实标签就不画 ROC。

## 5. 3D

- 只在第三维真有变量时用：空间结构、响应面、三维轨迹、优化地形。
- 用 `plot_surface` 平滑曲面，不画瀑布/幕布/3D 柱/3D 饼。
- 默认 `elev=25, azim=45, zoom=1.3`；曲面细网格边 `#5A5A5A`、0.35 pt、`rcount=37, ccount=40`。
- 必须配二维投影/切片/等高线；共享色标只画一次。
- 视角要可读；遮挡要交代；投影有歧义时加投影图。

## 6. 导出

- PDF/SVG 为主，PNG 300 dpi 为预览；TIFF 600 dpi 只在投稿包需要时出。
- `pdf.fonttype=42`、`svg.fonttype='none'`，文字可编辑。
- 物理宽度是契约：**不要用 `bbox_inches='tight'` 改交付图宽度**。项目 `lib.visualization.export` 刻意不 tight crop；本 skill 的 `save_figure` 也走它。诊断/预览图可以 tight，但要落 `tmp/`。
- 白底；不要 JPEG 线条图；不要放大位图冒充矢量。
- 导出后打开最终 PNG/PDF 检查：缺字、裁切、图例压线、同色混淆、轴范围、单位、区间含义。

## 7. 常见画风错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 8 个面板全 viridis | 颜色语义丢失 | `quantity=` 按物理量取 |
| 温度用 viridis | 冷=亮黄、热=暗紫，反直觉 | temperature→inferno |
| 低值平台占 80% 同色 | 场结构看不见 | gamma + 裁低端；还平改剖面 |
| 红蓝只靠颜色区分 | 灰度/色盲不可读 | 加线型/标记 |
| 图例无底色压在曲线上 | 标签读不出 | 白底半透明或移出 |
| 20 pt 面板字母 | 喧宾夺主 | 9–10 pt |
| `bbox_inches='tight'` 改交付宽度 | 论文嵌入尺寸失控 | 固定 mm 画布 + 手动 axes；tight 只用于预览 |
| 中文图用英文标题 | 与正文脱节 | 模板语言解析 |
| 3D 只有曲面没有投影 | 读不出数值 | 加 2D 投影/切片 |
