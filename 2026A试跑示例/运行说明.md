# 运行说明

本文使用的全部程序与结果都在提交件根目录下平铺存放（没有 `code/` 之类的前缀）。下面四
节分别说明**哪些是输入、哪些是程序生成的**、**装什么依赖**、**怎么跑出提交的结果**，以及
**哪些补充计算不在主流程里**。

## 一、文件准备

运行前，工作目录下应当有下面这些文件（本提交件里已经全部就位）：

| 文件 | 是什么 | 从哪来 |
|---|---|---|
| `附件1.xlsx` | 题目给定的输入数据：烘干初期各时间点烘房的温度与水分浓度实测序列 | 题目附件，不可缺 |
| `附件2.xlsx` | 题目给定的输入数据：烘干过程中各时间点药材半径的采样序列 | 题目附件，不可缺 |
| `core.py` | 共用内核（环境驱动、物性经验式、有限体积离散、时间推进、求根、导出） | 本提交件 |
| `q1.py`、`q2.py`、`q3.py`、`q4.py` | 四个子问题的求解入口 | 本提交件 |
| `run_all.py` | 主程序入口 | 本提交件 |
| `sensitivity.py` | 收敛性与敏感性诊断、守恒与恒等校核（不含在 `run_all.py` 里，见第四节） | 本提交件 |
| `summarize.py`、`validate_results.py` | 汇总登记与独立校验 | 本提交件 |

运行过程中**生成**的东西（不需要事先准备）：

| 路径 | 由谁生成 |
|---|---|
| `result1.xlsx` … `result4.xlsx` | 四个子问题求解后导出（也可由 `run_all.py` 一次生成） |
| `results/*.json`、`code/outputs/*.npz` | 求解、汇总与检验过程的中间与汇总产物（目录不存在时程序自己创建） |

程序内部的路径一律**相对当前工作目录**解析，并且模块之间是**同目录裸名导入**，所以把
上面这些 `.py` 与两个附件放在同一个目录里、在该目录下执行命令即可，不需要恢复任何目录结构。

## 二、安装依赖

Python 3.11，依赖为（版本取自本项目的 `requirements.lock.txt` 精确快照）：

```text
numpy==2.4.6
scipy==1.17.1
openpyxl==3.1.5
matplotlib==3.11.1
pandas==3.0.5
```

只跑主流程（第一节的求解与导出）需要 `numpy`、`scipy`、`openpyxl`；`matplotlib` 只在
重画论文插图时用到，`pandas` 只在补充的表格核对里用到。

```bash
pip install numpy==2.4.6 scipy==1.17.1 openpyxl==3.1.5 matplotlib==3.11.1 pandas==3.0.5
```

## 三、运行程序

```bash
python run_all.py
```

它依次完成：读两个附件 → 四个子问题求解 → 收支核对 → 导出 `result1.xlsx`–`result4.xlsx`
→ 检验。全部数值在交付档口径下算出（320 个径向单元；问题一、二、三的时间步长 1 s，问题四
60 s），与论文和结果文件里的数值同一口径。整条主流程在普通笔记本上约十几分钟。

只需要重跑某一问时，单独运行对应的入口即可（问题三要用到问题二的解，先跑 `q2.py`）：

```bash
python q2.py
python q3.py
```

## 四、补充计算

下面这些**不在** `run_all.py` 的主流程内，用来支撑论文里的检验与对照；它们只读求解产物，
不会改变任何交付数值。

```bash
python sensitivity.py        # 网格/步长/场级收敛、口径敏感性、守恒与恒等校核、解析级数解对照
python summarize.py          # 汇总四问结果并登记结构化指标
python validate_results.py   # 独立校验器：不引用求解器，只读结果文件重算约束与收支
```

- `sensitivity.py` 的三组收敛扫描与二维轴对称端面对照见论文第 6.1、6.2 节与附录 A.2、A.4；
- `validate_results.py` 是**另一条路径**的复核：它不 import `core.py`，只看交付出去的
  `result*.xlsx` 与汇总文件；
- 若只想做一次冒烟检查，可以用缩比档（只改网格与步长，不改方法）：
  `python run_all.py --scale 0.25`。**该档产出的数不是交付值**，交付值一律取默认档。
