# 赛题选择：执行规程（agent 直接可用）

> 本文件是给 agent 的执行指令，不是给人类的建议。 输入 = 本文档 + 当届三题题面与附件。按固定顺序跑完即产出 `PROBLEM_SELECTION.md` 并宣布「选定：X」。全程不需要人工干预。
> 版本：NewMathAgent，独立文档，不入 skills 链。

---

## 0. 执行入口与输入契约（先做）

1. 读取三题题面。题目文本位置：优先找 `request/` 下 `problem*.md` / `problem*.pdf` 或随题给出的三份题面；按文件名或内容区分 A/B/C。题面为真、不得臆造缺失数据。附件在对应 `data/` 或随题目给。
2. 若某题题面/附件读不到 → 该题标记「缺输入」，不参与打分，并在报告注明。
3. 固定顺序执行 §1→§5；**不跳过、不改权重**，除非权重严重背离本能力画像并在报告说明。
4. 全程给每个分数写**一句话题面证据**（哪句原文/哪个附件特征让你这么打），保证可复核。

---

## 1. 能力画像（选前对照题面核验，不自欺）

### S 级护城河（命中即优先）
- 第一性原理正向闭式内核：几何/运动学/光学/物理"机理→数值正演"可逐位复现。
- 多保真度：粗筛快判 + 稠密连续定稿审计（判据分快/准两档）。
- 分层优化：DE/可分性枚举/精确剪枝；门禁能独立复推并逼出更优。
- 定理规范化：能提炼出"被用到"的命题/引理并带推导；凸/单调/可分/驻点正交。
- 判据/口径纪律：能自定义口径并分层披露——有效/遮蔽/达标类更擅长。
- 工程交付：图/决策卡/交互 demo/可复现脚本全流程。

### D 级短板（命中即降预期）
- 纯统计挖掘/纯社科/商业风控/模糊问卷、无物理机理 → 易出学术负结果。
- 人人可套 XGBoost/LightGBM 的题 → 无代际优势。
- 以"创造并依赖硬定理/纯解析证明"为评分主轴 → 验证强、硬定理弱。
- 超大数据/需 GPU/OCR/外部 API → 本地单机难跑。
- 结果靠外部领域权威先验且查不到 → 判据无法自己算对。

## 2. Step 1 — 属性解构（逐题填表）

| 候选题 | 核心本质 | 变量维度/硬约束 | 交付形态 | 是否命中 S / 命中 D |
|---|---|---|---|---|
| A | | | | |
| B | | | | |
| C | | | | |

判读信号：
- 分问递进「Q1 固定复核锚定 → Q2 单点优化 → Q3 多点/升级判据」= 最稳形（S 全用上）。
- Q1 就要先"证明/推导解析结论" → 撞 D-纯证明，谨慎。
- 出现"新判据/更严口径"（多光束、更严遮挡）→ 判据升级发挥点，加分。

---

## 3. Step 2 — 四维雷达打分（满分 100，权重固定）

先**逐维按锚点定 1–5 分**，再 `维分 = 20 × 该维 1–5 档`（⑤ 例外见下），加权合计：

| 维度 | 权重 | 打分锚点（读题面后对号入座） |
|---|---|---|
| ① 机理确定性 / 正向闭式内核可行性 | **35%** | 5=有明确物理/几何正演式且你能写出并自检；3=半机理半查表/需要较多文献参数；1=纯黑箱/纯统计相关，无机理正演 |
| ② 算法护城河 / 多保真度优化展现力 | **25%** | 5=清晰优化/覆盖/指派结构 + 快慢两档判据必要；3=有优化但规模小或判据单档；1=分类/回归人人可套、无结构可秀 |
| ③ 纯数学命题抽象与公理化证明潜力 | **20%** | 5=题内能提炼"真被用到"的凸/单调/可分/正交引理；3=有一些结构但非必要；1=需创造硬定理或纯定义无证明空间 |
| ④ 采分点客观性 / 陷阱规避 | **20%** | 5=交付是控制量/物理标定量、数字说话、口径可复核；3=有主观成分但给固定口径即自洽；1=开放式政策/主观赋权/负结果高危 |

计分规则：`总分 = 20×(5 档分[①]×0.35 + [②]×0.25 + [③]×0.20 + [④]×0.20)`，即每维满档=满分贡献，总满 100。
附加：命中 D 短板一条 → ④ 至少 -1 档；命中 S 两条以上 → ② 或 ① 可 +0.5 档（写明依据）。

---

## 4. Step 3 — 一票否决（先于比大小）

命中任一条 → 该题踢出候选（不进入比大小；除非其余题全被否，才降级重估并在报告说明）：
- **[否 1]** 纯描述性统计调查 / 主观赋权评估 / 无物理机理仅相关性。
- **[否 2]** 核心采分点靠"开放政策建议 / 定性业务包装"。
- **[否 3]** 数据为高采集/测序黑箱噪声、无法建仿真自检闭环。
- **[高险·需 probe]** Q1 即纯定理证明，或超大数据/OCR/外部权威真值——先用 §5 probe 证能跑，跑不通即弃。

---

## 5. Step 4 — 30 分钟可行性 probe（对最高分且未被否的题做）

对首选 Q1 判据写 3–5 个小样例脚本（口径是否定得住、结果是否单调/量级合理、快判能否 <几秒）。
**判据 = Go；判据糊/翻口径/量级离谱 = No-Go**（弃，改测第二志愿）。把结果写进报告一行。

---

## 6. Step 5 — 终审与决策规则（确定性）

在未被否决且 probe Go 的候选里：
1. **取总分最高者**为选定题。
2. 并列或分差 ≤3 分 → 依次用：② 结构/优化分高者 > 命中"分问递进 + 新判据升级"者 > ① 机理正演分高者 > ④ 高者。仍同 → 选题型更贴近"固定锚定→单优化→多目标升级"者。
3. 若唯一高分被 §4 否决或 probe No-Go → 顺延次高分重复 §5–6。
4. 输出 `PROBLEM_SELECTION.md`（§7 模板）并在文件末尾写一行 **「选定：X」（X∈{A,B,C}）**。

---

---

## 8. 止损 / 换题触发（写进报告，开跑后仍可执行）

链早期（文献→建模评审前）任一见 → 按次高分顺延换题：
- 判据 probe 后仍反复翻口径；
- 核心是纯证明/超大数据/外部先验且确无解法；
- 建模评审两轮 REVISE 都指向"题意判据本身无解/自相矛盾"。
换题成本链早期≈0，越晚越贵。
