# 外部参考与授权原则

> 本 skill 的图型灵感来自若干公开的科研绘图与论文示意图项目。这里只保留**设计原则和
> 数据契约**，不复制上游代码，也不把外部仓库放进 `new math agent`。具体的第三方来源、
> 版本与许可证在项目外的参考目录里维护，不进入本仓库。

## 1. 数据图型库

- 不复制上游脚本；通用模板在 `studio.py` 里用本项目的风格重写。
- 外部模板默认带模拟数据；必须替换数据、样本量、模型名、统计标注。
- 没有真实区间/真实标签/真实加性贡献时，不画 CI、ROC 或 SHAP；按 `recipes.json` 的
  `fallback` 降级。

## 2. 比较与拼版

- 借鉴的是版式语言：宽画布、黑边柱、hatch、legend panel、分组比较、组成分解、拼版。
- 不复制上游代码；具体实现是 `grouped_bars`、`stacked_composition`、`plate_layout` 等。
- 如果某张图要复用第三方成品图，按对方许可证单独署名；本 skill 不内嵌这些成品。

## 3. 投稿契约与质控

- 借鉴的是 Figure contract、hero+evidence、多面板证据架构、渲染 QA、source data。
- 不复制上游 Python/R 模板；本项目的实现是 `figure-brief.schema.json`、`qa.md`、
  `statistics.md`、`source-data.md`。
- 统计口径与 source data 的规则以本项目文档为准，不依赖外部运行时。

## 4. 场图与 3D 内核

- 场图、等高线、3D 曲面、语义色阶、导出登记、目检签名全部住在本项目
  `lib/visualization/`，是跨题保留的底层。
- 外部 3D/流形示例只用于确认“第三维真有变量”这一判据，不复制其渲染代码。

## 5. 使用纪律

- 外部参考目录不是运行依赖；删除它不影响 `figure-studio`。
- 需要更新参考时，只更新设计原则/数据契约，不要把外部仓库搬进项目。
- 任何外部模板的许可证、版本、作者信息由参考目录自己维护；本仓库不记录这些字段，
  也不把它们写进图内文字。
