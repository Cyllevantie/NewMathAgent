# 构图：一张图只回答一个问题

> 多面板不是“把几张图拼在一起”。每个面板要承担**不同的推断角色**，按论证顺序排。
> 如果两个面板只是把同一证据换一种图再画一遍，删掉一个。

## 1. 六种 archetype

### `hero_evidence`（默认主图）

```text
┌──────────────────────────────┬──────────────┐
│                              │   b 效应/分布 │
│   a 主结果（42–60% 宽/高）    ├──────────────┤
│                              │   c 诊断/稳健 │
├──────────────────────────────┴──────────────┤
│   d 机制/时间线/敏感性（可选，横跨底部）       │
└─────────────────────────────────────────────┘
```

适合：一个主结果 + 2–4 个支撑证据。主面板占 42%–60%，辅助面板共享轴/色标。
例子：`图工作室/S01`（场 + 剖面 + 中心/表面 + 前沿）、投稿契约模块的 multipanel。

### `asymmetric_composite`

主面板明显更大，辅助面板不等宽。适合主结果有“场/图像”结构，辅助是异质证据（区间、分布、诊断）。不要让辅助面板平均分，平均分会把主结果压小。

### `quantitative_grid`

等权网格，适合多个同等重要的指标/条件。缺点是读者不知道先看哪；如果有一个明显主结果，改用 `hero_evidence`。

### `schematic_led`

```text
┌─────────────────────────────────────────────┐
│   a 机理/几何示意（主视觉，40–60%）           │
├───────────────────────┬─────────────────────┤
│   b 定量证据 1         │   c 定量证据 2       │
└───────────────────────┴─────────────────────┘
```

适合：有几何/物理对象，需要先讲机制再给证据。示意面板可以画圆柱/圆盘/边界条件/箭头/时间线；定量面板放前沿、剖面、敏感性。

### `plate`

竞赛论文的“一张大图讲完整故事”：机理 + 主结果 + 诊断 + 结论条。CUMCM 控制在 160 mm
（版心宽），Nature 双栏才用 183 mm；面板数 ≤6，不要把 200 mm 的答辩版直接塞进正文。

### `diagnostic_strip`

主图 + 残差/误差条带。适合预测/拟合图；主图讲一致性，条带讲误差随观测值的变化。

## 2. 面板角色

| role | 它回答什么 | 常见图型 |
|---|---|---|
| `hero` | 主结论是什么 | 场、主曲线、主 3D 曲面、机理主图 |
| `effect` | 效应有多大、方向如何 | 点区间、配对差、效应量 |
| `distribution` | 个体差异/形状/离群 | 云雨、箱线、直方、ECDF |
| `uncertainty` | 不确定性多大 | 区间带、误差棒、集合曲线 |
| `diagnostic` | 模型哪里错了 | 预测-观测、残差、偏差分箱 |
| `comparison` | 方法/条件谁更好 | 分组柱、点图、Taylor、雷达 |
| `composition` | 组成/占比怎么变 | 堆叠、组成热图 |
| `mechanism` | 为什么会这样 | 圆柱切面、边界条件、箭头、时间线 |
| `sensitivity` | 哪个口径最敏感 | 点图、龙卷风、扫描线 |
| `convergence` | 数值是否收敛 | 收敛曲线、网格/步长 |
| `context` | 数据/流程/事件背景 | 时间线、流程图 |

规则：**一个面板一个 role**。两个面板同 role 且同一数据 = 重复。

## 3. 面板顺序

- a 主结果（hero）→ b 效应/分布 → c 诊断/稳健 → d 机制/背景（可选）。
- 不要按数据表顺序排；按读者理解顺序排。
- 面板字母是论证顺序，不是生成顺序。
- 如果图要放进“问题分析”而不是“结果”，可以把 mechanism 放 a；但一张图仍然只回答一个问题。

## 4. 投稿契约示例的可借鉴处

这个外部示例的价值不是配色，而是：

1. **一主多辅**：每张图有一个明确 hero（配对轨迹、AUROC 矩阵、最低 RMSE 模型、气泡矩阵），辅助面板承担效应/覆盖/偏差/样本量。
2. **manifest 记录 counts/intervals/exclusions**：每张图的观测数、排除数、区间定义、重复单位都写清。
3. **四格式导出**：SVG/PDF 可编辑文字 + 600 dpi TIFF + PNG 预览；PDF 回读检查。
4. **QA 记录**：静态检查、PDF 预览、图片目检、修正记录。
5. **源数据 CSV**：每个面板的原始观测可追溯，聚合规则写清。

把它和比较与拼版的拼版语言结合：比较与拼版给“版式与视觉层级”，投稿契约示例给“证据角色与交付契约”。两者都不提供你的数据；数据必须来自你的 results。

## 5. 拼版大图的叙事条

大图底部或顶部加一条 1–2 行的“叙事条”，写清：

- 这张图在证明什么（一句 claim）；
- 主面板的读法（颜色/线/阈值）；
- 数据边界（提交版/试算/派生任务）。

叙事条不是图注的复制；图注在 LaTeX 里写方法和统计，叙事条只帮读者在图上定位。

## 6. 布局的物理约束

- CUMCM 正文版心约 160 mm；半栏 80 mm。Nature 双栏 183 mm；单栏 88 mm。
- 面板间距 3–5 mm；外边距 5–8 mm；不要用 `bbox_inches="tight"` 把交付图的物理宽度改掉（tight 只用于预览/诊断图）。
- 面板字母放在左上角外沿，物理偏移 5–7 mm；标题与字母之间留 3–4 mm。
- 共享色标放在主面板右侧或底部；不要每个面板一个色标。
- 图例优先放在面板外或空白角；中文模板用白底半透明框，英文模板只有在渲染检查无重叠时才可无框。
- 3D 面板与二维投影并排时，3D 占 60%–70%，投影占 30%–40%；共享色标只画一次。

## 7. 常见坏构图

| 坏构图 | 为什么 | 改法 |
|---|---|---|
| 2×2 四张同构折线 | 没有主次，读者不知道看哪 | 选一个 hero，其余改分布/诊断/敏感性 |
| 9 个小图拼贴 | 没有叙事，图注写不完 | 改成 `plate`，每行一个论证阶段 |
| 主面板 30%，图例/色标占 40% | 主结果被挤小 | 色标横放/共享，图例移出 |
| 每个面板都有标题+图例+色标 | 视觉噪音 | 共享标题/图例/色标，面板只留字母 |
| 3D 曲面 + 3D 柱 + 3D 饼 | 装饰大于信息 | 只保留真有第三维的 3D，其余 2D |
| 机理示意没有定量证据 | 像插图，不支撑 claim | 加前沿/剖面/敏感性中的至少一个 |
| 拼版图没有一句结论 | 读者看完不知道在证明什么 | 加叙事条/主标题 |
