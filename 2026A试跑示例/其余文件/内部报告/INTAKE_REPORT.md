## 4. 口径与坑（确认页之外还要盯的）

1. **「水分浓度」有两个意思**：药材的是**干基含水率**（初始 2.55 → 问题3 要降到 0.15 kg/kg 以下）；
   附件1 的「烘房的水分浓度」是**空气含湿量**（0.01963–`0.05025` kg/kg），量级差 50–100 倍。
   两者之间如何换算/衔接成边界条件，题面**没给**。
2. **T 的单位**：附件1 是 °C；附录3/附录4 的 D 用 `e^(−3850/T)`，其中 T 明写为 **K**
   （ρ、cp、k 只依赖 C，不涉温标）。
3. **`/` 不是 `×`**：三处 D 的指数都是分式（`−0.89/C`、`−0.45/C`、`−0.30/C`），见 §6.1 的证据。
4. **时间单位**：论文表用 **h**，而 `result3/4.xlsx` 的 A 列按附录1 用 **s**（60,120,180,…）；
   `result1/2` 的 A 列也是秒（1,2,3,…）。同一份结果两种时间单位，落盘时别混。
5. **result1/2 的行数**：模板只示范到第 3 行，实际要 t=1→1800 s 共 1800 行 × 21 列（0,0.1,…,2 cm）；
   result3/4 是 60 s 步 × 21 列。
6. **问题2 的交付时长自相矛盾**：表3/表4 只要 3 h，但题面说烘干持续 2–3 天，且 `result2.xlsx`
   未写截止时刻 ⇒「完整结果」到底存到 3 h 还是整个烘干过程，需要人拍板（见 §5 B4）。
